
# Todo App

A full-stack Todo app built with React (MPA-style) and Node.js/Express + SQLite.

## Features
- Add, edit, delete, mark complete todos
- View single todo details
- Backend CRUD API
- Unit tests

## Tech Stack
- Frontend: React, Vite, TypeScript
- Backend: Node.js, Express, TypeScript
- Database: SQLite
- Testing: Jest

## Getting Started
1. Install backend: `cd backend && npm install`
2. Install frontend: `cd frontend && npm install`
3. Run backend: `cd backend && npm run dev`
4. Run frontend: `cd frontend && npm run dev`

## API Endpoints
- GET `/api/todos`
- GET `/api/todos/:id`
- POST `/api/todos`
- PUT `/api/todos/:id`
- DELETE `/api/todos/:id`
